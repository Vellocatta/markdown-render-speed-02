A faster drop-in for marked 18.1.3 (GFM on), byte-identical HTML on all 720 practice cases. A surgical fork of marked: it vendors marked and subclasses its Tokenizer with a gated list tokenizer that skips the per-line block-start regex tests when a line's first non-space character cannot start one of those blocks.

## Run it

```sh
node main.ts
```
